
# 🚀 Física e Interacción 3D con Three.js

Proyecto desarrollado utilizando **Three.js** y **WebGL** para la implementación de un entorno interactivo en primera persona (FPS), incorporando física básica, navegación 3D y controles mediante teclado y mouse.

---

# 📚 Información Académica

- **Materia:** Programación Web / Gráficos 3D
- **Tema:** 3.4 Física e Interacción 3D
- **Alumno:** Jesús Roberto Hernández
- **Tecnologías:** HTML, CSS, JavaScript, Three.js, WebGL
- **Modalidad:** Individual

---

# 🎯 Objetivo

Desarrollar aplicaciones capaces de generar ambientes interactivos con objetos 3D utilizando controles FPS mediante teclado y mouse, haciendo uso de las librerías WebGL con Three.js.

---

# 🕹️ Características

✅ Navegación FPS (First Person Shooter)  
✅ Movimiento con teclado WASD  
✅ Control de cámara con mouse  
✅ Física básica y colisiones  
✅ Renderizado 3D en tiempo real  
✅ Integración de modelos GLTF  
✅ Interfaz futurista y responsiva  
✅ Publicación mediante GitHub Pages  

---

# 🎮 Controles

| Acción | Control |
|---|---|
| Moverse | WASD |
| Mirar | Mouse |
| Saltar | Espacio |
| Interactuar / Lanzar esfera | Click izquierdo |
